# 专业出路 · 专业-岗位匹配系统

大专生选了自己的专业和目标岗位之后，系统告诉他：**你离这个岗位还差哪几项技能、先补哪个**。

不给"XX 专业能做什么"的排行榜，给差距清单。

**在线地址：** https://cosmic-crumble-4f3174.netlify.app （手机、电脑都能开）

## 规模

- **30 个专业**：软件技术、计算机应用技术、计算机网络技术、移动应用开发、云计算技术应用、信息安全技术应用、物联网应用技术、大数据技术、人工智能技术应用、计算机信息管理、数字媒体艺术设计、视觉传达设计、广告设计与制作、产品艺术设计、动漫制作技术、影视多媒体技术、播音与主持、电子商务、网络营销与直播电商、市场营销、连锁经营与管理、国际贸易实务、现代物流管理、会计、金融管理、商务英语、文秘、旅游管理、酒店管理、法律事务
- **14 个岗位方向**，分五组：技术（前端/后端/测试/实施运维/技术支持/网络工程）、数据、设计（UI/平面/短视频）、产品与运营（产品助理/新媒体/电商）、服务（客服）
- **16 个发达城市**：北京、上海、深圳、广州、杭州、南京、苏州、成都、重庆、武汉、西安、天津、长沙、青岛、合肥、大连
- **68 项技能**，每项带阶段（基础/进阶/高级）、前置技能、一个能在宿舍做完的练手项目

## 每个专业看到的方向不一样

选完专业进入第二屏，只显示**这个专业推荐的 4-6 个方向**（软件技术 → 前端/后端/测试/实施运维/技术支持；会计 → 数据分析/电商运营/客服）。

想投别的，点「想看别的？查看全部 14 个岗位」就展开全部方向，按大类分组、按对口程度排序，跨方向会有「要多补一点」的提示。

## 三屏

1. **选专业** — 30 张卡
2. **岗位方向** — 本专业推荐的方向（可展开全部），显示核心技能与出现频率、大专可投比例；可按城市筛选、只看大专可投
3. **匹配器** — 勾「我会」的技能 → 实时算匹配度 → 缺哪几项 + 补齐顺序（按阶段和前置技能排）+ 每项配练手项目 + 技能频率图

## 数据是真的

- `data-src/jd-raw/`：真实招聘 JD 原文（智联招聘公开页面），每条带来源 URL，汇总在 `data-src/sources.json`
- `data-src/cards/`：招聘列表页的岗位卡片，用来统计学历要求
- `scripts/build-stats.mjs`：从原文统计技能出现频率 → `src/data/stats.json`
- `scripts/pick-skills.mjs`：按实测频率给每个方向排技能（本版人工终选也全部基于实测值）
- 权重不手填：出现率 ≥50% 记核心 3 分，25–50% 记重要 2 分，其余 1 分；已剔除资深/经理岗

**当前样本：180 条有效 JD**（前端 21、运维 19、UI 17、客服 16、电商 14、技术支持 14、测试 13、后端 12、新媒体 11、网络 10、视频 10、平面 8、数据 8、产品 7）

## 跑起来

    npm install
    npm run dev                   # 开发
    npm run build:single          # 打包成单文件 dist/专业出路.html
    node scripts/build-stats.mjs  # 重新统计技能频率
    node scripts/pick-skills.mjs  # 按频率重排每个方向的技能

## 已知限制

- **薪资区间未采集**：招聘网站不登录只显示 `**-**元`，本版界面不显示薪资
- 样本量不均：前端 21 条，产品助理只有 7 条，小众方向的百分比误差大，界面上都标了样本数
- 分城市学历样本只覆盖部分城市（北京最全），缺样本的城市显示「本城样本不足」，退回全国样本
- 客服、产品助理这类方向 JD 里技能词很少，可匹配的技能项偏少
