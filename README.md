# 专业出路 · 专业-岗位匹配系统

大专生选了自己的专业和目标岗位之后，系统告诉他：**你离这个岗位还差哪几项技能、先补哪个**。

不给"XX 专业能做什么"的排行榜，给差距清单。

**在线地址：** https://cosmic-crumble-4f3174.netlify.app （手机、电脑都能开）

## 三屏

1. **选专业** — 软件技术 / 数字媒体 / 电子商务
2. **岗位方向** — 前端 / 后端 / 测试 / 实施运维，带入门薪资、核心技能标签、大专可投比例，支持按城市、只看大专筛选
3. **匹配器** — 勾选"我会"的技能 → 实时算匹配度 → 输出缺哪几项 + 补齐顺序 + 每项配一个能练手的小项目

## 数据是真的

- `data-src/jd-raw/` 里是抓到的真实招聘 JD 原文（智联招聘公开页面），每条带来源 URL，汇总在 `data-src/sources.json`
- `scripts/build-stats.mjs` 从这些原文里统计每项技能的出现频率，生成 `src/data/stats.json`
- 权重不手填：出现率 ≥50% 记核心 3 分，25–50% 记重要 2 分，其余 1 分；已剔除资深/经理岗
- 当前样本：**71 条有效 JD**（前端 16 / 后端 17 / 测试 18 / 运维 20），采集于 2026-11-03

算出来的前几项：前端 Vue 56%、HTML/CSS 50%；后端 Java 94%、Spring Boot 71%、MySQL 71%；测试 HTTP 与接口 67%、缺陷管理 56%；运维 网络基础 70%、故障排查 65%。

**大专可投**只有一套口径：招聘页学历标注里明确写「大专 / 学历不限 / 中专 / 高中」的比例。某城样本不足 8 条就不单独统计，退回全国样本，界面上标了样本数。

## 跑起来

    npm install
    npm run dev          # 开发
    npm run build:single # 打包成单文件 dist/专业出路.html
    node scripts/build-stats.mjs  # 重新统计技能频率

## 已知限制

- **薪资区间未采集**：智联不登录只显示 `\*\*-\*\*元`，界面上沿用占位区间并标注「待补」
- 每个方向样本 16–21 条，频率有 ±10% 左右的误差
- 反爬限制导致分城市样本不全，缺样本的城市会显示「本城样本不足」

## 目录

    src/views/        三个屏
    src/lib/match.js  纯函数：算分、排补齐顺序
    src/data/         majors / jobs / skills / stats
    data-src/         抓下来的 JD 原文与招聘卡片
    scripts/          统计脚本、单文件打包脚本
