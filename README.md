# 专业出路 · 专业-岗位匹配系统

大专生选了自己的专业和目标岗位之后，系统告诉他：**你离这个岗位还差哪几项技能、先补哪个**。

不给"XX 专业能做什么"的排行榜，给差距清单。

**在线地址：** https://cosmic-crumble-4f3174.netlify.app （手机、电脑都能开）

## 规模

- **16 个专业**：软件技术、计算机应用技术、计算机网络技术、大数据技术、人工智能技术应用、数字媒体艺术设计、视觉传达设计、动漫制作技术、影视多媒体技术、电子商务、网络营销与直播电商、市场营销、物流管理、会计、商务英语、旅游管理
- **12 个岗位方向**，分四组：
  - 技术：前端开发、后端开发、软件测试、实施/运维、技术支持、网络工程师
  - 数据：数据分析
  - 设计：UI/交互设计、平面设计、短视频剪辑
  - 运营：新媒体运营、电商运营
- **68 项技能**，每项带阶段（基础/进阶/高级）、前置技能、一个能在宿舍做完的练手项目

## 三屏

1. **选专业** — 16 张卡，选完影响岗位排序和「跨方向」提示
2. **岗位方向** — 12 个方向按大类分组，显示核心技能与出现频率、大专可投比例；可按城市筛选、只看大专可投
3. **匹配器** — 勾「我会」的技能 → 实时算匹配度 → 输出缺哪几项 + 补齐顺序（按阶段和前置技能排）+ 每项配练手项目 + 技能频率图

## 数据是真的

- `data-src/jd-raw/`：抓到的真实招聘 JD 原文（智联招聘公开页面），每条带来源 URL，汇总在 `data-src/sources.json`
- `data-src/cards/`：招聘列表页的岗位卡片，用来统计学历要求
- `scripts/build-stats.mjs`：从原文统计技能出现频率 → `src/data/stats.json`
- `scripts/pick-skills.mjs`：按实测频率给每个方向排技能（本版的人工终选也全部基于实测值）
- 权重不手填：出现率 ≥50% 记核心 3 分，25–50% 记重要 2 分，其余 1 分；已剔除资深/经理岗

**当前样本：157 条有效 JD**（前端 21、运维 19、UI 17、电商 14、技术支持 14、测试 13、后端 12、新媒体 11、网络 10、视频 10、平面 8、数据 8）

**大专可投**只有一套口径：招聘页学历标注里明确写「大专 / 学历不限 / 中专 / 高中」的比例。某城样本不足 8 条就不单独统计，退回全国样本，界面上标了样本数。

## 跑起来

    npm install
    npm run dev                   # 开发
    npm run build:single          # 打包成单文件 dist/专业出路.html
    node scripts/build-stats.mjs  # 重新统计技能频率
    node scripts/pick-skills.mjs  # 按频率重排每个方向的技能

## 已知限制

- **薪资区间未采集**：招聘网站不登录只显示 `**-**元`，本版界面不显示薪资，只用技能和学历说话
- 每个方向样本 8–21 条，频率有 ±10% 左右的误差；样本越小的方向越要小心看
- 反爬限制导致分城市样本不全，缺样本的城市显示「本城样本不足」
- 新增方向（平面设计、数据分析等）样本量偏少，后续继续补
